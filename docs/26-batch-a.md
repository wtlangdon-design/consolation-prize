## Notes

1. **Room 19's wall: "Somebody before me wrote a number on the wall beside the bed and crossed it out. The number was two hundred."** Doc 05's town sign says the smallest repainted population underneath is two hundred. Somebody in this room was counting the same thing. Nothing says so.
2. **THE COFFINS · USE — "Not yet."** It is the same line in Act III, when Thad is arranging his own funeral in this room. Adding a variant would be explaining the joke.
3. **The undertaker's window is left with the blind up so a visitor can see Boot Hill.** He has arranged his workshop so the answer is visible before he has to say it.
4. **Room 18's stove has a rail for drying gloves, and nobody in Consolation owns gloves.** The hotel was built for a town that never arrived.
