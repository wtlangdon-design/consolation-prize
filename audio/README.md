# Music beds

Empty, and named in `content/manifest.json` before anything is here, so the
thing being commissioned has somewhere to land.

`consolation-title.ogg` is doc 45's **O-01-M**: CONSOLATION, full, piano-led —
doc 28's title mix. Tyler has approved the melody as heard in
`proofs/audio/consolation-audio-proof.html`.

**The proof is not the deliverable.** It synthesises live, and errata 49 rules
for rendered stems: *a synthesised solo fiddle playing THADDEUS is the most
recognisable "this is a computer" sound in game audio, and it would be playing
during the moment the game is about.* Producing that melody as a rendered stem
— played, or sequenced against decent sampled piano, fiddle and jaw harp — is
what is outstanding.

**Room beds are absent on purpose.** Room 1's is **O-02-M**, the THADDEUS
fragment, and THADDEUS has not been written. `manifest.music.rooms` is empty
until it is.

A missing file is silence, not an error. `engine/core/Music.ts` survives
every path here being absent, which is why the game runs unchanged today.
